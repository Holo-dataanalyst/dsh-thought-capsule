# 思维胶囊 · 新手教程

> 面向第一次用的人。跟着做完「五分钟上手」，就能把后面所有功能用起来。
> 遇到问题直接跳 [常见问题](#常见问题)。

## 这是什么（30 秒）

一个**低摩擦暂存箱**：干活时想到的点子、要试的插件、要回头查的链接，一句话丢进去，之后再整理。
它不写笔记、不做知识库、不做任务看板——只负责「先记下来，别忘」。

两条 AI 联动是它独有的：

- **转给 AI**：把某条（或某几条）胶囊放进某个会话的输入框，自己按回车才发。
- **找我漏掉的待办**：让 AI 读你最近的会话，把没落地的待办捞成一张表。

## 第一次打开（3 步）

1. **左侧栏找胶囊图标**：一颗横向的胶囊形状（中间一道虚线），点开就是面板。
2. **面板顶部是输入框**：写一句，`Enter` 保存（`Shift+Enter` 换行）。
3. 存进去的东西默认在 **「未整理」** 页签 —— 这是收件箱，先攒着，回头再分类。

> 找不到图标？见 [常见问题](#常见问题) 第 2 条。

## 五分钟上手

### 第 1 分钟：记三条

在输入框里分别输入下面三句，各按一次回车：

```
待会试试 better-sidebar 这个插件
周报里要补上损耗率的环比
https://example.com/article 回头读
```

第一条大概率进「插件/工具」，第三条进「阅读/资料」——**分类是按关键词自动猜的**，不用你选；猜错了在卡片上手动改一下即可。

### 第 2 分钟：整理一条

在「未整理」页签点某一行的 **「待办」** 按钮（状态段控的第二个）——它就从收件箱挪进待办了。
同时行尾的分类下拉框可以直接改成别的分类，比如把「插件」改成「灵感」。

### 第 3 分钟：改一个字

点行尾的 **✎**，正文变成输入框：改完 `Enter` 保存，`Esc` 取消。
（胶囊一旦存下就能随时改，不用删了重记。）

### 第 4 分钟：做完它

做完了点 **「完成」**。想收藏起来又不想留着的，点 **「归档」**（带归档时间，之后仍能移回来或删除）。

### 第 5 分钟：看看这周

页签下面「分类」那一行的最右边点 **「本周回看」**：这周新增/完成/归档各几条、哪个分类最活跃、哪些待办超过 7 天没动。
这个统计是本地算的，**不调用模型**，点一下就出结果。

## 五个日常场景

### 1. 随手记：桌面悬浮胶囊

面板右上角 ⚙ →「在桌面上显示彩色思维胶囊」，屏幕右下角会出现一颗小球。

- 点一下 → 弹便签，写完 `Enter` 保存，直接进「未整理」
- 按住拖动 → 换位置，位置会记住
- ⚙ 里可调：大小、便签字号、便签透明度、展开方向、图标（emoji 或上传一张 <100 KB 的图）
- **`Alt+C`** 全局开关这颗球（正在输入框里打字时不会抢键）

### 2. 读文章时抓一句话：划词捕获

在任意页面选中一段文字（至少 2 字），选区上方会浮出 **「记下来」** 小气泡，点一下就成了「阅读」胶囊，还会记下它来自哪个会话。

- 这个功能**默认关闭**（聊天里划词复制太常见，默认开等于到处冒泡）
- 开启位置：面板 ⚙ →「划词时浮出「记下来」小气泡」，或设置卡里的同名开关

### 3. 找东西：搜索

输入框下面那行就是搜索框，边打边筛（正文、标签、分类都能命中），只作用于当前页签 + 当前分类。
`Ctrl/⌘ + K` 或 `/` 跳到搜索框，`Esc` 清空。

### 4. 一次交好几条：批量转给 AI

在卡片操作行最左边勾上想交出去的几条 → 顶部出现「已选 N 条」条 → 点 **「批量转给 AI」** → 选目标 → **「准备提交」**。

### 5. 回顾：本周回看 / 归档页

- 「本周回看」= 这周的量化回顾
- 「归档」页签 = 做过但不删的，能移回待办，也能删除

## 把胶囊交给 AI

### 单条

卡片上点 **「转给 AI」**，面板展开一块：

1. **选目标**：默认「新会话」，也可以选某个已有会话（列表已按工作区排除归档会话）
2. 选了工作区后，会话列表只显示**那个工作区里能用的会话** + 新会话选项
3. **补一句**（可选）：比如「拆成三条待办」
4. 点 **「准备提交」**

它做的事：把胶囊正文（含 id / 状态 / 分类 / 来源会话 / 标签 / 截止 / 更新时间）+ 你补的话放进那条会话的输入框，**并打开那个会话，但不会发送**——你确认后自己按回车。
点了「复制」则只把文本复制到剪贴板。

**转出之后**：
- 这条胶囊自动变成 **「已完成」**（已经归档的不动）
- 卡片上出现「转给会话 xxxx」徽标，点它跳回那条会话
- 不会再夹带别的胶囊——交出去的就是你勾的那几条

### 让 AI 主动记

你说「记一下 / 别忘了 / 待会试试这个」时，AI 会直接写进胶囊（工具 `capsule_add`），并回执分类与状态。
它读胶囊用 `capsule_list`，改状态/分类/正文/标签/截止日用 `capsule_update`。

**没有删除工具**：AI 删不掉你的胶囊，删除只能在面板里由你自己点 ✕ 确认。

### 让 AI 找回漏掉的待办

面板右上角 **「找漏掉的待办」**：AI 读你最近的会话，把没落地的待办列成表（事项 / 出自会话 / 判断依据）。
每一行可以 **「存胶囊」** 或 **「忽视」**，会话名可点开跳回去。全程不新开会话。

## 设置在哪

| 想改什么 | 去哪 |
|---|---|
| 悬浮球开关/大小/图标/透明度/方向、便签字号、划词捕获、导出 JSON | 面板 ⚙，或 **设置 → 插件 → dsh-thought-capsule** 的设置卡（两边同一份配置，改完互相同步） |
| 分组（分类） | 面板分类那一行的 **「+ 分组」**，自建分组 id 形如 `g-xxxxxxxx` |
| 数据备份 | 设置里的 **「导出 JSON」** |

### 快捷键

| 键 | 作用 |
|---|---|
| `Enter` | 保存（输入框 / 便签 / 编辑中） |
| `Shift+Enter` | 换行 |
| `Ctrl/⌘ + K`、`/` | 跳到搜索框 |
| `Ctrl/⌘ + E` | 跳到记录输入框 |
| `Ctrl/⌘ + Enter` | 保存当前输入 |
| `Esc` | 逐层收起：发送面板 → 本周回看 → 清空搜索 / 取消编辑 |
| `Alt + C` | 显示/隐藏桌面悬浮胶囊 |

## 数据与备份

- 数据文件：`<profile 目录>\.dsh-thought-capsule\capsules.json`（单文件，纯 JSON）
- 实际路径看 `GET /thought-capsule/api/health` 返回的 `dir` / `file`
- 备份：设置里点「导出 JSON」，会下载整库；换机器时把它放回同名位置即可
- 写入方式是「备份旧文件 → 临时文件 + 改名 → 回读校验」，写坏了会自动用 `.bak` 恢复

## 常见问题

**1. 改了代码 / 更新了插件，界面没变？**
刷新页面（`Ctrl+R`）。看当前版本：控制台执行 `__dshThoughtCapsuleDebug()`，或访问
`http://127.0.0.1:3080/thought-capsule/api/client-report` 看 `build`。

**2. 左侧栏没有胶囊图标？**
先访问上面的 `client-report`：
- 404 → 宿主半边没加载（查 profile 接线、junction、桌面端是否重启过）
- `applied:false` → 客户端脚本跑了但 `apply` 没被调用
- `slotsResolved:false` → 席位名不对
- `registered` 里没有 `sidebar.panellist` → 席位注册失败，看 `failures`

**3. 存下来的东西在哪？**
只看存在哪：见上面「数据与备份」。界面里按页签看：未整理 / 待办 / 完成 / 归档 / 全部。

**4. 悬浮球挡事？**
拖动它到别处；或 ⚙ 里关掉；或按 `Alt+C` 临时收起。和别的桌宠共存时只留一个。

**5. 划词没有气泡？**
先在设置里开「划词捕获」。另外选区至少 2 个字。

**6. 为什么 AI 说它不能删胶囊？**
这是故意的：删除不可逆，只留给你在面板里点 ✕（会二次确认）。

**7. 标签和截止日怎么填？**
目前只能由 AI 记录（你说「周五之前交，标签叫报价」这类）或调 API 写入；面板里可以**看到**它们，但还没有手动编辑控件。

**8. 转给 AI 后内容重复了？**
「准备提交」只填草稿不发送。如果目标会话本来就有草稿，插件不会覆盖它，会提示你先清空那边输入框。

## 卸载 / 回滚

1. 删掉 profile 的 `package.json` 里 `dsh-thought-capsule`（`dependencies` 一行 + `dsh.profile.bundles` 一项），或恢复 `package.json.bak-thought-capsule`
2. 删掉 `node_modules\dsh-thought-capsule` 这个 junction
3. 重启桌面端

数据不会跟着删：`capsules.json` 还在原地，重新装回来就能继续用。
